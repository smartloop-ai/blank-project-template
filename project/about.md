What is Smartloop?

Smartloop is an AI agent orchestration tool for extracting information and performing tasks. It is designed to run entirely on your local machine. Its orchestration loop selects models based on their capabilities and the workload to produce results efficiently. Instead of relying on a single large model, Smartloop uses an agentic approach to break problems into smaller tasks, delivering comparable results locally without the infrastructure and token costs required by much larger models.

Build custom skills and connect external tools to combine them with your personal documents, generate new content, and perform external tasks such as creating a ticket.

A user prompt is used to match relevant skills. These skills can span multiple steps, including generating reports, making tool calls, and summarizing the output.

The orchestration selects the best model for each task based on capabilities, size, and other factors, while staying within available resource constraints.
